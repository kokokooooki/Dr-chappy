# Dr. Chappy v0.1

Slack `app_mention` events -> Vercel -> fixed Slack reply.

## Endpoint

`/api/slack`

## Required Vercel environment variables

- `SLACK_BOT_TOKEN`
- `SLACK_SIGNING_SECRET`

Do not commit either secret to GitHub.

## v0.1 goal

Mention Dr. Chappy in Slack and receive a fixed reply.
AI-generated replies will be added only after this transport path works.
